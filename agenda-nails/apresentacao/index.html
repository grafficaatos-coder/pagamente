Dúvidas frequentes

O que você precisa saber antes de começar.

Funciona no celular?

Sim. O Agenda Pro é responsivo e pode ser usado no navegador do celular. Também pode ser instalado como aplicativo compatível.

Serve somente para salão de beleza?

Não. O sistema foi pensado para vários tipos de atendimento, incluindo clínicas, terapeutas, psicólogos, esteticistas, consultórios e profissionais autônomos.

Posso cadastrar meus próprios serviços?

Sim. Você define nome, duração, valor, status ativo e também pode controlar onde o preço aparece.

O cliente consegue confirmar o horário?

Sim. O sistema pode enviar um link de confirmação. Quando o cliente confirma, o status do agendamento é atualizado automaticamente.

Os dados de uma empresa aparecem para outra?

Não. Cada empresa trabalha com seus próprios cadastros, clientes, serviços e agendamentos.

Preciso instalar programa no computador?

Não. Basta acessar pelo navegador. Isso facilita o uso em diferentes computadores e celulares.
